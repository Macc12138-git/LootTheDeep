# 搜索与背包交互样板

直接用浏览器打开 `index.html` 即可，无需安装依赖。也可以在本目录执行 `python3 -m http.server 8765`，访问 `http://localhost:8765`。

这是独立的 HTML / CSS / JavaScript 演示，不连接 Unity 或存档。刷新页面或点击“重置演示”会恢复初始物品。视觉和数值为原型建议。

- 左侧为像素潜水员与装备展示；中间为 5列×10行背包（50 格，格子适应背包宽度，内部仅纵向滚动）；右侧为 6×4 维修箱。
- 容器物品紧凑排列，按从上到下、从左到右的顺序逐件搜索。未搜索物品显示灰色占格阴影，放大镜与进度显示在当前物品上，不透露名称和品质。
- 自动逐件搜索，每件 1.5 秒；暂停、关闭或页面失焦会中断当前物品，已发现物品保留。
- 点击物品查看详情，拖拽整理或跨容器转移；拖拽时按 R 旋转，绿框可放、红框不可放。直接选中后按 R 也可原地旋转。
- Ctrl / Command + 点击快捷转移，或使用详情栏转移按钮；无连续空间时保持原物品。
- Esc 关闭，E 重新搜索，Tab 开关独立背包。Tab 在本样板中作为游戏快捷键。
- 所有物品只在本次页面会话中保留；没有入库、结算、装备属性、堆叠或自动整理。
- 窄屏隐藏角色展示，优先保留两个物品区域；手机宽度时上下排列。

文件分工：`index.html` 页面结构与手绘 SVG 图形；`styles.css` 视觉和适配；`app.js` 搜索状态、格子数据与交互。

背包内部仅支持滚轮上下滚动和触控板纵向滑动；拖拽位置会根据滚动偏移计算。

左右物品格使用同一个尺寸，根据两侧可用宽度统一计算；背包为5列，容器为6列，连续格子间距为0；独立胸挂袋位、口袋之间保留9px间隔。

随身收纳增加一种分隔胸挂（2×2主袋＋两个1×2侧袋，共8格）、四个独立1×1口袋、3×3保险箱。加上原50格背包，共71格。区域间支持拖拽，各独立袋位不能跨袋放置；快捷转移仍以背包作为默认接收区域。保险箱目前仅展示收纳布局，不预设死亡保护或结算规则。

收纳区顺序为胸挂、口袋、背包、保险箱；保险箱始终在最下方。连续格子无内边距和格间距，保留格线。

胸挂、口袋、背包和保险箱的格子左侧各有48px装备图标区域，与格子间隔10px；该区域不占用物品格。
