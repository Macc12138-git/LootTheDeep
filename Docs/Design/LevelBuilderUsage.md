# 关卡编辑器使用说明

入口：`LootTheDeep → 关卡编辑器 → 打开制作场景`。窗口也可由 `开发者模式 → 关卡搭建`（`Ctrl/Cmd + Shift + F3`）打开。操作发生在专用的 `Assets/Scenes/MapEditorScene.unity` 和 Unity Scene 视图中，原 ExploreScene 保留为演示回归场景。

`Ctrl/Cmd + Shift + F10` 检查当前布局，`Ctrl/Cmd + Shift + F11` 保存并试玩。

正式关卡资产是 `Assets/Maps/` 下的 **Map 预制体**，不是制作场景。制作场景仅是共用工作台/草稿，可编辑不同地图；`MapPlaytestScene` 从保存的 Map 加载玩法环境。`Assets/Editor/LevelBuilder/素材库.asset` 与模块是编辑素材；Map 数据组件与地图资产可供运行时使用。首版没有运行时关卡编辑、地形程序生成、持续刷怪或正式基地入库。

## 第一次使用

1. 打开制作场景，默认提供 `Assets/Maps/Map_001/Map_001.prefab` 示例地图，包含绕行墙体、3 个容器、2 个出生候选、2 个撤离候选和 1 个敌人区域。
2. 点击“新建 Map”制作空白地图，或“打开 Map”加载已有预制体。设置编号、名称及每局出口数量。新地图先铺地，再放候选点和其他内容；地图范围由实际绘制的瓦片自动确定，无需预设尺寸。
3. 上方素材库五类为地图、容器、出生点、撤离点、敌人区域。地图分类包含内嵌的原生 Tile Palette、模块与静态障碍。展开场景绑定可指定/新建容器搜索区域。素材库与下方属性区采用上下布局，中间分隔条可拖动调整高度，两区内容分别滚动；窗口最小宽度为 480，窄窗口工具栏自动分行。
4. 点击“Tile Palette 绘图”直接在编辑器里选取瓦片，再到 Scene 绘制；目标自动绑定当前 Map 的 Ground，不必另开 Palette 窗口。也可从 `LootTheDeep → 关卡编辑器 → Tile Palette 地形绘制` 进入。选择模式保留 Unity 原生框选和移动；Alt、中键和右键视图操作保留。选中对象后在下方配置实例属性。
5. 点击“检查布局”并定位错误。“保存”只导出 MapRoot 子树；初次选文件名，后续更新同一预制体且保持 GUID。“另存为”生成独立资源，不覆盖其他地图。
6. 点击“保存并试玩”，在独立 MapPlaytestScene 加载刚保存的地图；WASD 移动、原有鼠标战斗、F 搜索、Tab 背包、按住 E 撤离。M 打开地图，M/Esc 关闭；查看时暂停行动，只显示地形、静态障碍和本局有效撤离点，详见[地图使用说明](MapUsage.md)。
7. 退出 Play 自动返回制作场景，恢复原视角/选择。敌人移动、死亡、容器搜索和物品状态不写回资产。需启用 Unity Scene Reload，关闭时会阻止工具试玩。

切换 Map 前会提示保存/放弃/取消；关闭 Unity/切换场景时 Unity 的场景保存提示保存的是工作草稿。要更新正式 Map，使用面板“保存”，不要只按 Unity 的保存场景。未完成的地图可保存，但试玩必须通过检查。Map 不允许引用制作场景外对象，也不包含玩家、摄像机、UI 或生成后的活体敌人。

MapRoot 下固定组织 Terrain、Obstacles、Containers、PlayerSpawnPoints、ExtractionPoints、EnemyRegions，保存地形、导航和内部引用，范围从地形计算，不再单独保存手动矩形。试玩环境独立保存在 `Assets/Prefabs/Development/MapPlaytestRig.prefab`，复用现有玩家、摄像机、HUD、库存、战斗会话和输入系统；不通过运行旧场景生成器重建地图。

## 原生 Tile Palette 与地图模块

- “地图 → Tile Palette”直接嵌入 Unity 原生调色板和工具条，替代原先的单格素材列表。支持原生 Palette 下拉、瓦片布局取样、框选多格组合、笔刷选择与设置；保留当前已选调色板，无已选项时优先使用 `Assets/Map/Tile/MapBase.prefab`。
- 在调色板单击瓦片或拖动框选组合，然后在 Scene 单击/拖动铺设。工具条使用原生选择、移动、笔刷、矩形、吸管、擦除、填充、旋转与翻转，不再由自制地形笔刷接管鼠标。
- Unity 默认快捷键：`S` 选区、`M` 移动、`B` 笔刷、`U` 矩形、`I` 吸管、`D` 擦除、`G` 填充、`[`/`]` 旋转、`Shift + [`/`]` 翻转；以 Unity 工具提示和自定义快捷键配置为准。使用原生 Undo/Redo。
- 面板显示当前绘制目标，始终指向本 Map 的 `Terrain/Ground`，新建/打开地图时自动更新。切换到模块、障碍、容器或标记工具会退出原生绘制；重新启用原生工具会结束布局工具，避免双重放置。点击顶部“选择”恢复普通对象选择。
- 内嵌调色板每次进入默认锁定，仅取样，不改共享 Palette。要整理调色板本身，可显式使用原生编辑锁；该操作修改的是共享 Palette 资产，和“保存 Map”不同。
- **框选模块**：拖出矩形，松开后保存到 `Assets/Editor/` 下。记录每个格子的 Tile、空格、颜色、变换、碰撞类型和锁定标记，只包含地形。
- 在“地图模块”分类选择模块，Scene 显示预览和范围；Q/E 或窗口按钮每次转 90°，单击写入目标 Tilemap。一次放置一次撤销。
- “覆盖已有地块”开启时，模块内的空格也会清除目标地块；关闭时仅在空地写入非空地块。
- Esc 取消自制模块/对象/标记工具；原生绘制的取消与撤销沿用 Unity 规则。自制模块捕获/放置限制为 16384 格，原生绘图工具不套用该限制。

地图使用当前导航支持的、无旋转且正缩放的 XY 矩形网格，允许平移。模块和目标 Grid 的格子尺寸需相同；地形/墙体沿用单 Tilemap 与 Tile 碰撞类型，不新增隐式地形层。“保存 Map”将当前地形写入所绑定的 Map 资源，不改共享地块与旧 MapBase。

### 自动地图范围

- “地图设置”只读显示实际瓦片的外接矩形尺寸和起点；绘制可向任意方向扩展，擦除边缘自动收缩，清空后显示“尚未绘制地形”。原生笔刷预览不计入，撤销/重做直接跟随瓦片结果。
- 外接矩形用于 Scene 范围辅助显示和试玩镜头边界，不表示矩形内所有位置都能行走。实际通行由地面与障碍决定，内部空洞和外侧空白均不可走；玩家碰到空白边缘时可沿边移动。
- 出生点、撤离点按实际地面和导航检查，不再要求手动扩展范围。空白地图可保存草稿，但不能试玩；地形需位于 Z=0 单层网格。
- 旧 Map 无需补填或迁移范围，加载时直接根据保存的瓦片计算；旧的手动范围不再生效。地图文件仍需通过面板“保存”更新。

## 容器、出生点、撤离点与敌人区域

在对应分类选素材，Scene 有半透明预览，单击连续放置，Esc 返回选择。启用网格吸附时落在格子中心，关闭后按鼠标世界位置放置。

- 出生点是候选标记，不是把测试玩家存进地图。每局从启用候选中选择一个，试玩可指定出生点和测试种子。
- 撤离点可配置名称、交互距离、按住 E 的时间。按出生点的可达出口集合随机启用指定数量，至少一个，本局保持稳定。集中选择最近可交互出口，多个点不会互相覆盖提示；不要求清空敌人。结算仍为测试，未入基地仓库。
- 敌人区域：Scene 拖动矩形创建，下方属性区配置尺寸、敌人 prefab 和各自数量，也可快速添加素材库中的枪手/突进敌人。开局按测试种子一次性生成在区域可通行、不与其他敌人重叠且距玩家出生至少 3 单位的位置。若空间不足则阻断试玩，不少生或静默跳过。区域仅管初始分布，不强制约束后续追击，也不增加波次或重生规则。
- 容器归入“场景绑定”指定的区域，运行时由原搜索系统发现。默认物资箱按约 1.1 世界单位显示，仍保持原有无实体碰撞的行为。名称、类型、搜索时间、容量、掉落表与区域归属可修改；“打开容器详细配置”复用区域与爆率工具。
- 掉落表、区域配置是共享资源。下方属性区修改其引用只影响实例；修改共享资源内容会影响所有引用者。详细配置窗口提供另存副本方式。
- 将已有静态 2D 障碍预制体拖入“添加资源”，在障碍分类点击“加入当前分类”。在 Inspector 编辑素材库可设置该素材的名称、放置缩放及是否允许旋转；角色方向沿用预制体，不使用障碍旋转工具。
- 障碍素材位于“地图 → 障碍”。选中容器、搜索区域、出生/撤离标记、敌人区域或 Obstacles 直属障碍，可吸附、复制、批量删除，支持 Undo/Redo；不将 MapRoot 和地形误当布局对象删除。

所有布局操作使用 Unity Undo/Redo。资产保存是项目资源创建，撤销模块列表引用不会自动删除磁盘上的模块文件。需要清理时在 Project 中管理资源。

## 辅助显示与检查

可显示地图范围、局部网格、静态碰撞轮廓、容器搜索距离、出生/撤离点与敌人区域。勾选“Scene 预览敌人位置”按同一测试种子预览落点，不生成运行敌人、不抽取物资。试玩可打开 Gizmos 显示全部出口候选，未启用候选不能交互。拾取路径起终点可显示实际绕行路线。

本窗口打开时，笔刷、模块、对象操作、原生移动工具、Tile Palette 和撤销/重做的地图与障碍改动会触发延迟导航刷新；鼠标拖绘期间延后刷新，不清理原生笔刷预览。也可显式点击“同步导航”。刷新会处理 Tilemap 碰撞变化，重新收集当前场景启用的静态非触发障碍，排除角色与弹丸，并重建导航缓存。关闭窗口后通过其他方式搭建时，试玩前应重新打开工具同步导航。

内嵌界面使用当前 Unity 6000.3 的公开 Tile Palette UI 控件；原生绘制服务启停尚无公开接口，因此仅对注册/注销 painter-interest 两个内部方法做集中适配，不修改 PackageCache，也不依赖隐藏 Palette 窗口。升级 Unity/Tilemap 包后需重跑集成验证；接口不存在时面板会明确报错。

“检查布局”与“保存并试玩”检查层级/内部引用、网格、是否存在地形及其 Z 层、候选出生点、每个出生点的足量可达出口、敌人区域容量/配置、容器掉落规则、区域归属以及从每个出生点的搜索可达性。搜索可达性采样容器周围 0.4 单位间距的位置，要求身体可站、处于实际搜索距离内且无遮挡，不要求箱子中心可走。非常狭窄的边缘仍需实际试玩。

没有敌人或任意增删容器均可正常检查。检查通过不代表敌人密度、攻击平衡、随机掉落总容量或正式基地闭环已经验收。当前搜索物品仍属于本局，不表示永久资产结算已实现。

## 验证入口

- `关卡编辑器 → 验证自动地图范围`：在临时附加场景检查自由扩展/擦除收缩、空图、负坐标、预览排除、撤销/重做、出生点/空洞通行、玩家移动、镜头/玩家加载绑定及预制体重开；结束清理本测试资源，不保存用户当前地图。最新结果写入 `Temp/MapBoundsValidation.txt`。
- `关卡编辑器 → 验证上下布局`：使用临时的 480 宽窗口检查垂直分区、对齐、属性区可见高度与原生调色板尺寸，结束关闭测试窗口，不改变原窗口的停靠布局或地图数据。
- `关卡编辑器 → 验证 Tile Palette 集成`：验证原生控件挂载、绘制服务、目标绑定、工具互斥、预览、组合拾取/绘制/旋转/翻转、矩形/擦除、Undo/Redo、导航与 Map 导出重开；只创建并清理本测试的临时地图资源，不修改共享 Palette 或示例 Map。
- `开发者模式 → 验证关卡搭建（编辑测试）`：在临时附加场景验证绘制、撤销/重做、非方形模块旋转、空格覆盖、实例复制、区域、导航与搜索距离、保存重开；结束清理临时场景与模块，不改探索布局。
- `关卡编辑器 → 验证 Map 存取与检查`：在临时附加场景验证 Map 创建、五类持久化、重复保存/GUID、独立另存为、重开、新建、容量/出生/出口/外部引用检查，结束清理本测试创建的资源。
- `关卡编辑器 → 验证加载搜索撤离与试玩隔离`（Ctrl/Cmd + Shift + F1）：使用示例 Map 的绕墙夹具验证独立加载、导航、出生/出口、敌人落点、F 搜索、E 撤离、重试和退出恢复。运行时保持 Game 窗口获得焦点，失焦会由现有会话逻辑暂停；不是任意地图都适用的几何夹具。
- `开发者模式 → 验证试玩隔离（运行测试）`：保留原 ExploreScene 的旧隔离回归，不用于新 Map。
- `开发者模式 → 检查当前布局`：通用布局检查，不要求固定敌人或容器数量。
- 原战斗和搜索回归菜单更名为“验证演示布局战斗/搜索（运行测试）”。它们仍使用原始 2 敌人、5 容器及出生点附近箱子的演示夹具，**不用于任意新布局的验收，也不会阻止保存与试玩**。敌人寻路运行测试继续独立保留。

测试临时对象不进入正式布局；工具不自动提交或推送 Git。
