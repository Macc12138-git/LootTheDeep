# 《Loot The Deep》游戏概念方案 V0.3

- 记录日期：2026-10-16。
- 状态：当前整体概念基线；描述目标玩法，不代表对应功能已经实现。
- 本轮明确调整：从水下探索转为较为开放的世界探索；探索与基地建设均采用 2D 像素风俯视角，地图使用 Unity Tilemap 制作；核心玩法继续采用搜打撤。
- 玩法方向补充：参考《元气骑士》的直观动作反馈、可读攻击、武器差异与遭遇节奏，并转译到可自由选路、可避战、由玩家自主撤离的搜打撤结构；不照搬横版视角或强制通关关卡。
- 设计边界：明确方向、沿用规则与建议示例的区分，见[设计理念与接续指南](DesignPrinciples.md)。具体地区、设施和撤离形式为建议，尚非逐项定案。
- 历史版本：[游戏概念方案 V0.2](GameConcept-v0.2.md)，保留水下主题的历史讨论。

## 一、游戏定位

**2D 像素风、俯视角、纯单机的世界搜打撤游戏，以基地建设承接长期成长，地图使用 Tilemap 制作。**

玩家拥有一处可以持续建设的基地，通过准备装备、选择目标区域，进入外部世界搜索资源，应对敌对人类 AI 及其他待设计的威胁，并通过有效撤离将物资带回基地。

成功撤出的资源用于扩建基地、建设设施、制作装备和准备下一次行动。玩家既要考虑本局值得带走什么，也要考虑下一项建设需要什么。

**成功撤离，物资入库；行动失败，承担本次投入与收获的损失，具体损失范围待定。**

## 二、从 V0.2 到 V0.3 的调整

| 事项 | V0.2 | V0.3 |
| --- | --- | --- |
| 探索主题 | 潜水与海底探索 | 较为开放的世界探索 |
| 探索视角 | 具体 2D 视角尚未定案，曾建议横向侧视 | 明确采用俯视角 |
| 地图制作 | 制作方式尚未明确 | 使用 Unity Tilemap 制作地图 |
| 局外成长 | 水面基地建设 | 俯视角基地建设，基地地点由后续世界观确定 |
| 行动对象 | 围绕潜水器和潜水装备讨论 | 围绕世界探索重新设计角色、装备及交互方式 |
| 环境与敌人 | 海底环境、变异鱼与敌对打捞者 | 按新世界观设计环境及敌人；敌对人类仍由 AI 驱动 |

本次调整改变主题、视角和地图制作方向，继续沿用纯单机、局内搜打撤、局外基地成长、四种随机机制和撤离入库规则。

潜水器操作、氧气压力、艇体耐久和变异鱼等保留在历史方案与原型记录中，不作为 V0.3 的默认要求。新世界观、玩家控制实体、武器类型与弹药规则需要重新细化。

## 三、整体结构：基地与探索两层循环

### 场景 A：基地——局外建设与准备

基地采用俯视角，承担长期资产保存、设施建设和行动准备：

- 储存、整理和使用成功撤出的物资。
- 布置、建造和升级基地设施。
- 制作、维修装备，准备工具与补给。
- 根据建设目标确定本次探索需求。
- 选择目的地和配装，开始下一次行动。

### 场景 B：探索区域——局内搜打撤

探索同样采用俯视角，每次进入区域是一局独立行动：

- 从本局确定的出生点进入地图。
- 自主选择路线，搜索物资和高价值容器。
- 与敌人交战，或利用路线、地形和时机避战。
- 根据收获、状态和撤离情报调整计划。
- 抵达有效出口，完成撤离并结算。

```text
基地：建设 / 仓储 / 制作 / 配装
                  ↓ 选择探索区域，投入装备
探索：随机出生 → 自由规划路线 → 搜索与战斗或避战 → 有效撤离
                  ↓
成功：携带物资入库
失败：结算本次损失（具体范围待定）
                  ↓
基地：使用收获，发展设施，准备下一次行动
```

V0.3 先沿用基地与探索区域分离的场景结构。“较为开放”当前体现为单局区域内的自由探索、多条路线与自主目标选择。世界是否无缝连通、多个探索区域如何连接及跨区域如何结算仍待确认；若后续调整连接方式，需要同时设计撤离与资产结算边界。

## 四、动作战斗参考方向

本项目参考《元气骑士》的战斗可读性、直接反馈、武器差异和遭遇变化，以增强俯视角探索中的动作张力；不照搬横版视角、角色技能结构、关卡房间推进或具体数值。其[官方介绍](https://www.chillyroom.com/zh/game-news/2/8)可作为参考来源；房间节点分类另有[社区维基整理](https://yqqs.huijiwiki.com/wiki/%E5%85%B3%E5%8D%A1%E6%A8%A1%E5%BC%8F)，非官方且版本可能变化。具体参考边界见[设计理念](DesignPrinciples.md)。

### 战斗目标

- 敌人攻击给出清晰预警、方向或危险范围，让玩家能通过走位、掩体、反击或脱离应对。
- 战斗节奏紧凑、命中与受击反馈明确；仍需给玩家理解当前局势和作出路线选择的空间。
- 武器类型应形成有辨识度的射程、节奏或风险取舍；具体武器、操作与弹药规则待定。

### 遭遇组织

地图上的战斗、搜索、补给、特殊事件和高价值目标用于构成不同节奏，不默认组织成必须清空才能继续的封闭房间。

- 普通遭遇原则上可以交战、绕行、潜行或撤退。
- 高威胁敌人或首领式目标可以作为可选风险峰值，提供额外收益或路线情报，但不锁住基础撤离，也不以击败目标自动完成行动。
- 遭遇密度、精英/首领是否存在，以及是否采用房间式局部空间仍待验证；如果使用封闭战斗空间，不能让它取代全局地图上的自主选路与撤离判断。

### 局内武器与成长

本局发现的武器、补给或战术强化可以作为候选，用来临时改变后续打法；是否采用局内强化、强化形式和数量均未定案。局内临时收益不自动变成永久解锁。要将战利品带回基地，仍必须有效撤离；基地长期成长继续由入库物资、制作和建设承接。

本方向的核心约束是：**战斗让路线选择更有张力，不能替代搜索；击败敌人不是通关条件；撤离始终由玩家决定。**

## 五、世界探索与 Tilemap 地图

### 开放感来自路线与目标选择

玩家可以根据建设需求、地图情报、当前状态和风险预期决定去哪搜、搜多久、何时撤离。

以下地区用于说明探索与资源主题，不锁定世界观或首张地图内容：

| 区域示例 | 搜索内容与探索特点 |
| --- | --- |
| 林地与野外营地 | 基础资源、补给和隐藏储藏点，路线较分散 |
| 聚落与街区 | 房屋、商店与仓库，提供室内外搜索和巷道绕行 |
| 工业与维修区域 | 工具、机械部件与电力设备，建设目标明确 |
| 废弃设施与遗迹 | 关键设备与稀有物资，需要更多进入和撤出准备 |

道路、建筑和野外通路应提供可辨认的路线关系。玩家可以快速穿过主路，也可以绕行、进入建筑细搜，或只搜索外围后撤离。高价值目标分布在不同候选位置，促使玩家根据本局情况取舍。

### 地图制作与随机化分开设计

地图明确使用 Unity Tilemap 制作。当前建议采用**手工制作地图骨架＋局内要素随机化**：

- 用 Tilemap 制作地面、道路、建筑墙体、障碍和区域边界。
- 先保证可通行路线、地标、掩体及出口的空间关系。
- 将可搜索容器、敌人、交互设施和撤离点作为独立对象，与地图关联。
- 保留地标和区域资源主题，通过物资、高价值目标及有效出口的变化改变每局计划。

手工地图骨架是本版建议，地图规模、分区数量、地图拼接和程序生成比例仍待确定。采用 Tilemap 不等于已经确认整张地图的生成方式。

## 六、局内搜、打、撤

### 1. 入场：围绕本次目标准备

玩家从基地选择装备、工具和补给，决定本次行动投入。轻装适合降低失败成本，更充分的准备可以支持高风险搜索。

例如，为建设电力设施出发时，可以优先准备适合搜索维修厂和电力区域的工具，再根据携带空间和风险承受能力选择武器与补给。

### 2. 搜索：发现资源并判断价值

搜索对象可以包括房屋储物柜、工具箱、医疗柜、仓库货箱、遗留背包以及可拆解设备。

不同区域和容器提供不同收益预期，具体内容按规则随机。搜索和开启需要时间，部分操作会制造声音。有限的携带空间要求玩家选择带走哪些物资。

物资价值同时取决于稀有度和基地需求：急需的普通建设部件，可能比暂时用不上的稀有物品更值得带走。

### 3. 战斗：读懂攻击、选择交战或脱离

战斗围绕俯视角地图中的距离、掩体、通路和退路展开。敌人攻击需要清晰可读，玩家可以靠走位、掩体、武器特性和时机处理威胁。敌对人类由 AI 驱动；其他敌人种类、行为和环境威胁根据世界观继续设计。

玩家可以主动交战获取额外收益，也可以观察、绕行、潜行或撤退。遭遇不默认要求清场；战斗可能带来暴露、受伤、装备损耗和时间消耗，战后是否停下搜索遗留物也需要取舍。高威胁目标可作为可选的高风险高收益节点，不阻断有效撤离或强制结束行动。

本局找到的武器或战术强化可以改变当前打法，但具体是否加入仍待确认；作为战利品带回基地的物品只有成功撤离后才入库。原潜艇靶场及战斗原型中的两武器槽、有限弹匣和无限备弹属于历史测试规则。新概念下的玩家控制实体、移动、瞄准、武器与弹药消耗尚未定案，不直接套用旧规则。

### 4. 撤离：将局内收获转为长期资产

**搜到物资并放进背包，不代表已经获得永久资产；成功撤离后，战利品才进入基地仓库。**

当背包变满、找到关键材料或状态恶化时，玩家需要停止搜索并规划撤离。撤离必须抵达本局有效出口、满足条件并完成对应过程。

## 七、四种随机机制

| 随机要素 | 规则方向 | 对行动的影响 |
| --- | --- | --- |
| 随机出生地 | 从合理的候选入口中选择本局出生点 | 改变初始路线和目标顺序 |
| 随机物资 | 按区域主题和容器规则生成内容 | 有方向地寻找资源，同时保留收获差异 |
| 随机高价值容器 | 从候选位置中生成，数量和内容可变化 | 促使玩家探索、绕路或重新选择目标 |
| 随机撤离点 | 每局从候选点中确定有效出口 | 改变搜索顺序和撤离路线 |

随机机制遵守以下边界：

- 出生位置安全合理，不直接产生必死开局。
- 每局至少提供一个玩家有条件抵达和使用的出口。
- 有效出口在本局确定后保持稳定，并提供可理解的提示。
- 高价值目标不固定在同一个位置。
- 出生点与出口不必重合。
- 稳定地标支持玩家积累地图知识，随机局势促使玩家调整计划。

## 八、撤离点与情报

以下为候选形式，首版采用哪些类型仍待确认：

| 撤离类型 | 表现示例 | 决策作用 |
| --- | --- | --- |
| 基础撤离 | 区域边界的有效通道 | 提供本局基本退出途径，可能需要较长路程 |
| 条件撤离 | 需要开启或恢复供电的设施出口 | 消耗时间、工具或材料，换取不同路线 |
| 呼叫撤离 | 激活接应点并等待 | 可以主动启动，声光和等待可能增加风险 |

建议入场提供基础撤离方向，其余情报通过现场标识、地图终端或探索发现。情报显示精度、撤离耗时和具体条件留待细化。

撤离附近的冲突由敌人活动、玩家行为和局势共同产生，不要求每次撤离都强制发生防守战。

## 九、俯视角基地建设与物资用途

基地是长期保留、可以持续扩建的独立场景。玩家利用带回的材料建设设施，逐步提升仓储、加工、装备准备与探索能力。

首轮可以考虑以下设施，具体形式和配方为待验证建议：

| 设施建议 | 主要作用 | 产生的探索需求 |
| --- | --- | --- |
| 仓储设施 | 存放、整理物资，扩展储存能力 | 基础建材与储存部件 |
| 工作台 | 制作工具、补给与基础装备 | 工具、材料和专业部件 |
| 维修设施 | 修复行动中受损的装备 | 金属、机械部件与维修用品 |
| 电力及生产设施 | 支持更高级的制造和建设 | 电力部件与关键设备 |
| 行动准备区 | 配装、选择目的地并出发 | 下一次行动所需的装备与补给 |

基地建设应持续产生明确的探索目标。例如，建设发电设施时主动寻找电力区域，扩建仓库时优先携带基础建材。

物资继续按用途区分为基础材料、行动补给、专业部件、关键设备和稀有战利品，稀有度另行配置。具体掉落与成长测试草案见[物资与掉落概念方案 V0.1](LootAndDropConcept-v0.1.md)。其中概率、容器数量和成长节奏仍需结合新地图与行动体验验证。

建议保留“找到完整设备”与“收集部件组装”两条建设路径，使玩家既能获得意外惊喜，也能看到多次行动的积累。

基地的建造操作、建筑占地、是否自由摆放、设施依赖与升级配方尚待设计。生存消耗暂沿用随行动和生产推进的建议，避免离线持续消耗；具体指标仍待确认。

## 十、成功、失败与长期成长

### 成功撤离

带出的战利品进入基地仓库，玩家可以储存、加工、制作或投入建设。携带装备的消耗与损坏按后续规则补充和维修。

### 行动失败

暂沿用以下建议：

- 损失本次带入的可丢失装备和剩余补给。
- 损失本次搜到但未撤出的物资。
- 保留基地建筑、仓库存货和长期解锁。
- 提供低成本恢复行动的途径，支持连续失败后重新出发。

装备保护、回收、死亡惩罚和具体损失范围仍待确认。现有背包原型中的保险箱布局不代表死亡保护规则已定案。

### 长期成长

基地成长增加设施、仓储容量、加工能力、装备选择和工具用途，让玩家能够准备更多类型的行动，逐步探索更危险、收益更高的区域。

高价值行动继续保留风险，避战和低风险探索也应能推进基础建设。

## 十一、一局典型体验

你准备在基地建设一台发电机，目前缺少电力部件。

出发前，你选择基础武器、医疗用品和开箱工具，进入一张包含林地、聚落和维修厂的探索地图。本局林地营地有一处敌人活动点，维修厂深处则有高威胁守卫；它们是可选遭遇，不会封锁全图通路或基础撤离。

本局从林地入口进入，已知的基础撤离点位于地图另一侧。你先搜索沿途营地，再绕开聚落中的敌对 AI，进入维修厂寻找部件。一次遭遇中敌人的攻击预警让你及时退到墙后；你选择不在此处耗费补给，继续从侧路前往目标。

搜索过程中，你发现一个高价值设备箱，获得了需要的电力组件和一件占用较多空间的稀有物资。

设备箱附近的守卫构成可选高威胁目标。你可以尝试击败它争取额外收益，也可以拿到所需部件后直接离开。此时继续探索可能获得更多收益，但当前携带量、状态和出口位置让撤离成本增加。你决定放弃部分普通材料，为关键物资腾出空间。

你调整路线，避开交火区域，抵达有效出口并完成撤离。

回到基地后，物资正式入库。你建好发电设施，获得新的生产能力，再为下一次探索准备装备。

该示例说明建设需求如何影响探索、收获如何改变计划，不锁定具体设施、物品或地图配置。

## 十二、首轮验证与接续边界

建议首轮验证一处俯视角基地、一张 Tilemap 探索地图、四种随机机制，以及准备、入场、搜索、战斗或避战、撤离、入库和建设的完整闭环。

优先观察：地图是否支持自由选路；敌人攻击是否易读且有应对空间；遭遇是否提供交战和绕行选择而不强迫清场；搜索目标是否清楚；找到关键物资后是否会主动考虑撤离；带回资源是否能推动一项可见的基地建设。

以下事项仍待确认：

- 世界观、美术主题、首张地图内容与规模。
- 世界是否无缝连通、探索区域如何连接及跨区域结算方式。
- 玩家控制实体、角色移动、战斗操作、武器与弹药规则，以及是否加入局内武器拾取或临时强化。
- 敌人攻击预警、遭遇密度、高威胁/首领式目标及其奖励规则。
- 基地建造方式、占地规则、设施配方与成长节奏。
- 撤离形式、情报精度、单局时长和时间压力。
- 装备损失、保护与恢复机制。
- 正式背包规则、经济数值、存读档及随机种子持久化。

纯单机方向继续保留，不包含联机、真人匹配和多人服务器玩法。复杂居民管理、大规模基地攻防、自动化工厂和庞大阵营系统暂不纳入首轮范围。

已有搜索背包、容器掉落、射击和战斗文档保存各自的方案与原型记录；旧主题示例或验证结果不能视为 V0.3 的俯视角世界探索、Tilemap 地图或基地建设已经完成。本次更新仅调整设计文档。

后续核心方向变化应同步维护[设计理念与接续指南](DesignPrinciples.md)、根目录 `AGENTS.md`、`README.md` 和受影响的专题方案。V0.2 及旧主题原型保留为历史参考。
