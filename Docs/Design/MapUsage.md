# 地图界面使用说明

## 范围与操作

当前接入独立 Map 试玩流程，不提供角落常驻小地图。

- 按 **M** 打开地图，再按 **M** 或 **Esc** 关闭。
- 地图只显示实际地形、静态障碍与**本局有效撤离点**（绿色“出”图标）。未启用的出口候选不显示。
- 不显示玩家、敌人、容器、物品、出生点、路线或方向箭头；不提供实时定位导航。
- 完整地图默认可见，上北下南、等比例居中；不随玩家移动或旋转。首版无迷雾、探索记录、缩放、拖动和标点。
- 打开地图暂停行动时间、敌人、弹丸和换弹进度，并屏蔽移动、攻击、切枪、换弹、搜索、撤离及背包快捷键。
- 从背包按 M 进入时，先关闭背包、取消拖拽并停止搜索，物品不会因取消拖拽丢失。关闭地图不自动恢复背包或搜索。
- 打开地图会中断当前撤离读条；返回后需重新完成撤离过程。地图内持续按 E 不会撤离。
- 关闭地图的当帧不透传玩法按键；在地图中按住鼠标攻击，返回后需先松开再攻击。
- 失焦与地图暂停叠加：关闭地图不能解除失焦暂停，恢复焦点也不能解除仍打开的地图暂停。死亡/撤离结算后地图关闭且不能再打开。

## 数据与接入

- 正式地图数据仍为 `Assets/Maps/` 下的 Map 预制体，小地图/地图 UI 不写入 Map 资产。
- `MapTextureBuilder` 只读取 `MapRoot` 的地形与 Terrain/Obstacles 静态实体碰撞，不捕获游戏画面、角色或容器。地形空洞保留；组合墙体按轮廓填色，独立障碍按实际形状采样。
- `MapView2D` 位于 `Assets/Prefabs/Development/MapPlaytestRig.prefab`。加载器在本局出口选择完成后初始化地图；底图与出口图标本局生成一次，反复开关复用，重试/切图时释放旧底图。
- `CombatPrototypeSession2D` 统一处理 M/Esc、地图状态、失焦与结算暂停，并在玩法输入处理前裁决是否阻断。地图 UI 自身不独立修改时间倍率。
- 新建 Map 不需要单独设置地图界面；后续重建试玩 Rig 时自动带入地图 UI。既有 Rig 可使用 `LootTheDeep → 地图 → 安装地图界面`，仅更新这个预制体。
- 原 ExploreScene 演示流程不加入地图窗口；不改变搜索/掉落、撤离条件或测试结算规则，仍未接入正式基地入库。

## 验证入口

- `LootTheDeep → 地图 → 验证地图底图与界面`：在临时附加场景检查坐标、平移/缩放、预览瓦片排除、地形空洞、墙体/独立障碍轮廓、触发器和容器排除、有效出口、等比例布局及资源释放。
- `LootTheDeep → 地图 → 验证地图开关与行动隔离`：在本测试创建的独立临时场景检查 M/Esc、输入屏蔽、背包搜索/拖拽切换、暂停叠加、撤离、结算、重试与底图释放。需要 Scene Reload；不保存用户当前 Map 或制作场景。结束恢复原试玩启动场景及 Build Settings，并删除本次测试创建的临时场景。
- 最近结果写入 `Temp/MapFeatureValidation.txt`。验证记录以实际执行结果为准，不将既有战斗/搜索回归视作本轮已重跑。
