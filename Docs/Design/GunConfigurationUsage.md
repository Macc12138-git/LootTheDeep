# 枪械配置与武器系统使用说明

当前角色使用独立枪械配置表。Player 上的 `PlayerShooter2D` 负责输入、瞄准、武器显示及 HUD，`GunRuntime` 负责每把枪的弹药、射击冷却、换弹和随机分散。枪械数值只保存在配置表，运行状态按持有者独立维护，不回写共享配置。

## 修改枪械属性

在 Unity 菜单打开 **LootTheDeep → 武器 → 枪械配置表**，修改对应行后点击“保存配置”。默认配置资源是 `Assets/Data/Weapons/GunConfigs.asset`，也可以直接在 Inspector 编辑此资源。配置变更后重新运行游戏进行验证。

| 列 | 含义 |
| --- | --- |
| 武器 ID | 唯一标识；Player 的武器槽通过此 ID 查表 |
| 名称 | HUD 显示名称 |
| 弹容量 | 每个弹匣的最大子弹数，正整数 |
| 射速（发/分） | 每分钟射击数；单发间隔为 `60 / 射速` 秒，例如 1200 对应 0.05 秒 |
| 换弹（秒） | 从开始换弹到弹匣补满的耗时，必须大于零 |
| 分散半角（度） | 每发在瞄准方向的左右两侧独立、均匀随机取偏角；3 表示 −3° 到 +3°，0 表示直线射击 |
| 基础伤害 | 每发命中时结算的基础伤害，正整数 |
| 子弹速度 | 子弹移动速度，单位为 Unity 世界单位/秒 |
| 子弹预制体 | 子弹外观、碰撞体及生命周期资源 |

连续射击时每发单独抽取偏角，发射后保持该方向；不随准心转弯。分散度不随连续射击时间累积，不额外加入后坐力或弹道追踪。

## 当前配置与资源保留

`placeholder_gun` 是当前角色使用的占位枪：50 发、1200 发/分、换弹 1.8 秒、分散半角 3°、伤害 30、子弹速度 20，使用 `bullet.aseprite` 对应的 `PlayerBullet.prefab`。

旧 `Player.prefab` 完整保留，其主武器与副武器分别绑定 `prototype_main`、`prototype_secondary`。原弹容量、射击间隔换算后的射速、伤害、换弹时间和子弹资源均迁入同一配置表，旧武器保持零分散。

新增枪械时先在配置表添加一行，再在控制器的武器槽绑定该行 ID 以及外观对象、枪口、枪口闪光。Player 不保存枪械伤害、射速、弹容量等属性，不能通过 Player 设置一份独立数值。

当前沿用左键持续射击、R 手动换弹及无限备弹的原型行为。它们不代表最终弹药经济和装备带入、带出规则已经定案。

## 验证

菜单 **LootTheDeep → 武器 → 验证枪械系统** 检查配置合法性、两个 Player 预制体的绑定、射速换算、冷却、空仓、换弹、实例状态隔离和随机分散边界。此检查不改写场景或配置资源。
