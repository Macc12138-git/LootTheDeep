# 原始参考画风地图 V2

本版重新以用户提供的游戏截图为美术依据，保留多区探索范围和五类地图元素的限制。

## 参考依据

- `Tools/ImageGen/references/pixel-style-outdoor.jpg`：较粗的统一像素块、暗色阶梯描边、绿色地面与暖棕土路、简单物件阴影。
- `Tools/ImageGen/references/pixel-style-combat.jpg`：宽窄变化的土路与不规则开阔地、阶梯状地块边缘及可移动空间。
- `Tools/ImageGen/references/pixel-style-interior.jpg`：灰紫石墙、可见墙顶与较高正面、大块砖石结构。
- 所有分区都直接上传上述三张原始参考。布局引导图作为第四张输入，只规定连接位置及搜索点，不作为最终画风样板。

## 本版内容

- 绿色地面、棕色土路、灰紫石墙与石质地面、少量大块岩石、木箱或木质与蓝灰色箱子。
- 以局部残墙、宽阔岔路和不同大小的搜索空间组织路线，避免重复等大的院落和规则铺装路网。
- 每区按 6 个关闭容器规划，全图目标为 24 个。容器、出口与出生点的运行机制未包含在图片中。
- 草地表现为地面色块；未要求生成树木、灌木、草丛、花草或其他装饰物。继续禁止密集圆颗粒、凸点和噪点地面。

## 生成与使用边界

通过现有 imagegen 技能的 CLI/API 模式生成，使用 `edit`、`gpt-image-2`、`medium`、请求 1536×1152、不透明 PNG。四份最终提示词位于仓库 `Tools/ImageGen/prompts/validation-map-v2/`；ZIP 内附在 `prompts/` 目录。

`Tools/ImageGen/reference_map_v2.py` 只创建粗布局引导图并拼接生成结果，不负责调用图片接口。图片不是现成 Tilemap 图集，未修改 Unity 场景、碰撞、容器配置或玩法代码。实际视野、移动与搜索节奏仍须在 Unity 内验证。
