## 本轮布局建议

- 全图约按 96×72 格的世界尺度规划，每区约 48×36 格；这只是比例建议，图片没有切成严格网格或自动生成 Tilemap。
- 以约 24×36 像素的假想角色控制物件尺度，普通容器宽约 30–42 像素，道路宽约 90–110 像素；图片不绘制角色。
- 24 个关闭容器分散在多处院落和外围区域，用红色工具箱、蓝色柜子、木箱、橄榄色箱和金色特殊箱区分。
- 相邻分区各有两处道路连接；院落至少留两个开口，地面与院外道路提供横穿、外围绕行和回退空间。
- 左下西侧开口可作为入口候选，右上和右下东侧开口可作为撤离候选。这些是布局用途建议，未定义出生或撤离机制。
- 四区名称表示后续可配置的物资主题，图中只包含地面、道路、墙体、岩石障碍和容器，没有生成机器等额外设施。

## 生成与拼接记录

使用已配置的 imagegen 技能 **CLI/API 回退模式**，通过 `edit` 命令调用 `gpt-image-2`，质量 `medium`，请求尺寸 1536×1152，不透明 PNG。兼容服务没有严格返回请求尺寸，以上列出的均为实际文件尺寸。

先用 `Tools/ImageGen/validation_map_layout.py guides` 制作统一比例与连接位置的布局引导图。NW 使用对应引导图及 `Tools/ImageGen/references/pixel-style-outdoor.jpg`；其余三区使用各自引导图及 NW 原图作风格参考。

四份最终提示词位于仓库 `Tools/ImageGen/prompts/validation-map-v1/` 下的 `nw.txt`、`ne.txt`、`sw.txt`、`se.txt`；ZIP 中附在 `prompts/` 目录。它们保留最新参考图的清晰像素块、阶梯轮廓、有限明暗和稀疏扁平磨损，并明确禁止密集圆颗粒、凸点、噪声、植物、角色、文字与 UI。

拼接脚本统一泥土和道路的基础色，在内部接缝的小范围内按布局引导图校齐道路，保留外围岩石边界；没有对原画进行整体模糊。大图和四张最终分区来自同一次拼接，可按元数据无间隙还原。

从仓库根目录重新拼接现有原图，无需再请求图片接口：

```sh
Tools/ImageGen/.venv/bin/python Tools/ImageGen/validation_map_layout.py assemble
```

已检查 PNG 完整性、四区排列和连接口，尚未导入 Unity，也未验证碰撞、角色移动或单局时长。
