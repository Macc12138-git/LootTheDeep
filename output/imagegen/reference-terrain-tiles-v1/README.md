# 参考图地面与石墙边缘 Tilemap V1

按用户提供的局部截图生成：灰紫色低对比地面、灰石边缘、近黑紫色不可通行墙体填充。所有图块均为不透明 RGB PNG；深色部分是实际像素颜色。

## 文件

- `terrain-atlas-64.png`：正式图集，256×256，4 列×4 行，每格 64×64，无间距、无外边距。
- `tiles/`：16 张单独的 64×64 PNG。
- `atlas-preview.png`：图集放大预览。
- `assembly-preview.png`：使用本套图块拼接的检查示例，包含凹凸拐角和内部实心区域。
- `style-reference.png`：本轮用户提供的画风参考。

## 图块排列

以下方向均按地面或深色墙体在图块中的位置命名。

| 行 | 第 1 格 | 第 2 格 | 第 3 格 | 第 4 格 |
| --- | --- | --- | --- | --- |
| 第 1 行 | 地面 1 | 地面 2 | 地面 3 | 深色墙体填充 |
| 第 2 行 | 地面在上方的直边 | 地面在右方的直边 | 地面在下方的直边 | 地面在左方的直边 |
| 第 3 行 | 地面仅在左上角 | 地面仅在右上角 | 地面仅在右下角 | 地面仅在左下角 |
| 第 4 行 | 墙体仅在左上角 | 墙体仅在右上角 | 墙体仅在右下角 | 墙体仅在左下角 |

第 3 行用于地面外凸的角，第 4 行用于地面内凹的角。地面与墙体的基础分界对齐到图块中线，石边在墙体一侧。正式图集保持全部像素不透明，因此应使用配套地面和墙体图块连续铺设。

## Unity 导入

1. 将正式图集导入，Texture Type 设为 `Sprite (2D and UI)`，Sprite Mode 设为 `Multiple`。
2. Pixels Per Unit 为 `64`，Filter Mode 为 `Point`，Compression 为 `None`。
3. 在 Sprite Editor 中使用 `Grid By Cell Size`，设为 `64×64`，Offset 和 Padding 均为 `0`，Slice 后 Apply。
4. 将切分后的 Sprite 拖入 Tile Palette，通过地面、直边、角和深色填充组合地图。

验证包含：不透明像素、图块尺寸、同类连接截面像素一致性，以及拼接示例的视觉检查。未修改 Unity 场景；素材不含 Collider 或 Rule Tile 自动连接配置。当前 14 种基础地形组合不包含两块地面仅对角相接的情况，铺设时保持地面通过边相连。

生成方式：已配置的 API / `gpt-image-2`，一次参考图生成；随后在本地调整分界位置、匹配图块边缘并裁切打包。
